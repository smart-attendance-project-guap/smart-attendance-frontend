# Smart Attendance — Frontend

Общее приложение для студентов и преподавателей системы контроля посещаемости.

## Технологии

Next.js, React, TypeScript, Tailwind CSS, ESLint.

## Текущее состояние

Создана основа приложения. Проверены запуск, ESLint и сборка.
Страницы студентов и преподавателей пока не реализованы.
Backend ещё не подключён.

## Установка зависимостей

В терминале из папки проекта:

```powershell
npm.cmd ci
```

## Запуск для разработки

```powershell
npm.cmd run dev -- --port 3001
```

Открыть в браузере: http://localhost:3001.

Frontend использует порт 3001. Порт 3000 оставлен для локального Backend.

Для остановки сервера нажать Ctrl + C в терминале.

## Проверки

Проверка кода:

```powershell
npm.cmd run lint
```

Сборка приложения:

```powershell
npm.cmd run build
```

Команды приведены для Windows PowerShell.
В других оболочках можно использовать npm вместо npm.cmd.

## Совместная работа

- Используем один общий Next.js-проект.
- Изменения делаем в отдельных рабочих ветках.
- Общие страницы авторизации, компоненты и стили согласовываем между разработчицами Frontend.
- Не добавляем в Git файлы .env, пароли и токены.
- Форматы API согласовываем с Backend перед подключением.
